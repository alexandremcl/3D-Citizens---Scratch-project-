## 📖 About

**3D Citizen** is a project built entirely in **Scratch**, the visual programming language from MIT, by me, while I was a student at **Coláiste Muire, Crosshaven (Co. Cork, Ireland)**.

Scratch is a 2D environment by design. This project goes further by delivering a **three-dimensional** experience, which means rethinking how space, depth and the player's point of view are represented using nothing but blocks.

> 🎮 **[Play 3D Citizen on Scratch →](https://scratch.mit.edu/projects/484725866)**

## ✨ Why this project stands out

- **Pushing the tool beyond its limits**: building 3D in an environment designed for 2D is both a technical and a creative challenge.
- **100% Scratch**: no external libraries, only blocks, variables, lists and logic.
- **Nationally recognised**: awarded by a jury of professionals and computer science researchers.
- **Delivered under constraints**: designed and finished during the COVID-19 restrictions.

## 🎮 How to play

1. Open the project: **https://scratch.mit.edu/projects/484725866**
2. Click the **green flag** 🟩 to start.
3. Use the controls shown in the project instructions (keyboard / mouse).
4. Switch to **full screen** for a more immersive experience.

> 💡 Works in any modern browser, no installation required.

---

## 🧠 Concepts involved

- 📐 Representing 3D space and **projecting it onto a 2D screen**
- 🎥 Managing the player's **point of view**
- 🔁 **Game loop** and display refresh
- 🗃️ Data structures using **lists** and **variables**
- ⚡ **Performance optimisation** within Scratch's constraints
- 🧩 Code organisation with **custom blocks**
